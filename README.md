# ⚠️ Known Limitations

## Assignment Submission API

**Status: 🔴 Known Issue**

The assignment detail pages currently request:

```text
/api/norse-one/assignments/[id]/submission
```

The existing API route is present in the project:

```text
app/api/norse-one/assignments/[id]/submission/route.ts
```

However, the development server currently returns HTTP `404` responses for submission requests.

Example:

```text
GET /api/norse-one/assignments/assignment-001/submission 404
POST /api/norse-one/assignments/assignment-001/submission 404
```

The assignment pages themselves successfully load.

Therefore, the limitation is isolated to the existing assignment-submission API workflow rather than the entire assignment interface.

### Why it remains unresolved

Development was intentionally paused at this milestone rather than introducing additional architecture or unverified functionality.

The project goal at this stage is to:

> **Clean, stabilize, document, and publish the existing work without expanding the original project scope.**

Further investigation would require tracing the existing assignment page, submission request, dynamic API route, and database operation.

No additional submission system was added simply to hide the existing issue.
